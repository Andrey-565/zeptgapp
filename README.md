# 🎮 Minecraft Telegram Mini App

Готовое веб-приложение (Telegram Mini App) для авторизации и подтверждения входа на ваш сервер Minecraft. Работает на **GitHub Pages** (бесплатный постоянный HTTPS).

---

## 🚀 Пошаговая инструкция по запуску на GitHub Pages

### Шаг 1: Создание репозитория на GitHub
1. Перейдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите **New Repository** (или значок **`+`** в правом верхнем углу -> **New repository**).
3. Введите название репозитория, например: `minecraft-auth` (или `tgauth`).
4. Выберите тип: **Public** (обязательно для бесплатного GitHub Pages).
5. Не ставьте галочки "Add a README" и нажмите зелёную кнопку **Create repository**.

---

### Шаг 2: Загрузка файлов в репозиторий
Вы можете загрузить файлы любым удобным способом:

#### Вариант А: Через веб-интерфейс в браузере (Самый простой)
1. На странице созданного репозитория нажмите ссылку **uploading an existing file**.
2. Перетащите в окно браузера все файлы из этой папки:
   - `index.html`
   - `style.css`
   - `app.js`
   - `config.js`
   - `README.md`
3. Нажмите зелёную кнопку **Commit changes** внизу страницы.

#### Вариант Б: Через терминал Git
В этой папке выполните команды:
```bash
git init
git add .
git commit -m "Deploy Telegram Mini App"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН_GITHUB/minecraft-auth.git
git push -u origin main
```

---

### Шаг 3: Включение GitHub Pages
1. В вашем репозитории на GitHub перейдите во вкладку **Settings** (Настройки) -> меню слева **Pages**.
2. В разделе **Build and deployment**:
   - В выпадающем списке **Branch** выберите ветку `main` (или `master`).
   - Папку оставьте `/ (root)`.
   - Нажмите кнопку **Save**.
3. Подождите 1–2 минуты и обновите страницу. Сверху появится зелёная плашка с вашей ссылкой:
   `Your site is live at https://ВАШ_НИК.github.io/minecraft-auth/`

---

### Шаг 4: Настройка конфигурации

1. **В файле `config.js` (в репозитории):**
   - Укажите имя вашего сервера: `serverName: "Название Сервера"`.
   - Укажите логин вашего бота: `botUsername: "ИмяВашегоБота"`.

2. **В конфиге Velocity (`serv/velocity/plugins/tgauth/config.yml`):**
   - Вставьте полученную ссылку в поле `mini-app-url`:
     ```yaml
     mini-app-url: "https://ВАШ_НИК.github.io/minecraft-auth/"
     ```

3. **В @BotFather (настройка кнопки в меню бота):**
   - Напишите боту `@BotFather` команду `/setmenubutton`.
   - Выберите вашего бота.
   - Отправьте ссылку на ваш GitHub Pages: `https://ВАШ_НИК.github.io/minecraft-auth/`.
   - Введите название кнопки: `🎮 Войти в игру`.
   - Теперь у всех игроков прямо в поле ввода сообщений бота появится постоянная кнопка для запуска Mini App!

---

## 🔒 Как это работает:
1. Игрок заходит на сервер -> попадает на `hub` -> видит QR-код и 6-значный код сессии.
2. Игрок открывает Mini App (по QR, по ссылке или через кнопку меню бота).
3. Приложение отображает скин головы игрока, ник и код.
4. При нажатии **«Подтвердить вход»** Mini App отправляет подтверждение боту, а Velocity моментально телепортирует игрока на основной сервер выживания!
